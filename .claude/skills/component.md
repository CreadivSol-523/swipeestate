# Create New Component

Create a new React component for the CreadivSol project.

## Instructions

1. Ask for the component name if not provided as argument: $ARGUMENTS
2. Create the component inside `src/components/` following existing patterns
3. Use TypeScript (.tsx)
4. Use Tailwind CSS for styling (v4)
5. Use framer-motion for animations if needed
6. Export the component as default export
7. Follow the existing project structure and naming conventions
